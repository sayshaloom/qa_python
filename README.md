# BooksCollector — тесты

Тесты для класса `BooksCollector`, который хранит книги, их жанры и список избранного.

## Что покрыто тестами

Реализовано 12 тестовых функций (19 тестов с учётом параметризации), покрывающих все методы класса:

- **`add_new_book`** — добавление новой книги, повторное добавление уже существующей, граничные случаи по длине названия (пустое, 40 и 41 символ) — с параметризацией
- **`set_book_genre`** — установка валидного жанра существующей книге, попытка установить жанр, которого нет в списке, попытка установить жанр несуществующей книге — с параметризацией
- **`get_book_genre`** — получение жанра книги по имени (проверяется в связке с `set_book_genre`)
- **`get_books_genre`** — получение всего словаря книг
- **`get_books_with_specific_genre`** — получение списка книг определённого жанра, проверено для всех 5 жанров — с параметризацией
- **`get_books_for_children`** — фильтрация книг, подходящих детям (исключены жанры с возрастным рейтингом — Ужасы и Детективы)
- **`add_book_in_favorites`** — добавление книги в избранное, повторное добавление той же книги, попытка добавить книгу, которой нет в общем списке
- **`delete_book_from_favorites`** — удаление книги из избранного
- **`get_list_of_favorites_books`** — получение списка избранных книг

## Параметризация

Используется в 3 тестах, где сценарий один и тот же, а отличаются только входные данные:
- `test_add_book_with_long_title` — разные варианты некорректной длины названия
- `test_set_book_genre_for_existing_book` — валидный и невалидный жанр
- `test_get_books_with_specific_genre` — перебор всех жанров из списка

## Запуск тестов

```bash
python -m pytest -v tests.py
```
